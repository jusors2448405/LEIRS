🚨 TROUBLESHOOTING
────────────────────────────────────────────────────────────────────────────────

Issue: "Username and Password not accepted"
Fix:  1. Check 2FA enabled
      2. Generate NEW app password
      3. Remove ALL spaces from password
      4. Use full Gmail address

Issue: "Gmail credentials not configured"
Fix:  supabase secrets list
      supabase secrets set GMAIL_USER=...
      supabase secrets set GMAIL_APP_PASSWORD=...

Issue: Email not received
Fix:  1. Check spam folder
      2. Check Gmail Sent folder
      3. View function logs
      4. Verify recipient email

Issue: "Connection timeout"
Fix:  1. Check network connection
      2. Verify port 465 not blocked
      3. Try again in a few minutes
