# LEIRS Utility Scripts

This folder contains utility scripts used during development, testing, and database management.

## 📁 Script Categories

### Database Auditing
- `audit-database.js` - Database integrity audit
- `audit-test-data.js` - Test data verification
- `quick-audit.js` - Quick database health check
- `quick-check.js` - Fast system check

### Police Station Management
- `update-police-stations.js` - Update police station records
- `verify-police-stations.js` - Verify police station data
- `check-and-delete-charlie.js` - Check Test Police Station Charlie
- `mark-charlie-unavailable.js` - Mark Charlie as unavailable

### Data Analysis
- `investigate-duplicates.js` - Find duplicate records
- `execute-update-now.js` - Execute database updates

### Connection Testing
- `verify_new_connection.js` - Test Supabase connection

## 🔧 Usage

Most scripts require environment variables to be set in `.env` file.

```bash
# Example: Run audit
node scripts/audit-database.js

# Example: Verify connection
node scripts/verify_new_connection.js
```

## ⚠️ Important Notes

- These scripts were used during development and testing
- Some scripts may require Supabase credentials
- Always backup data before running update scripts
- Scripts are preserved for documentation and reference
